# SecureWipe 🛡️
> **Wipe. Verify. Certify. Protect.**

SecureWipe is a certified data erasure console designed for the secure retirement and recycling of IT assets (laptops, desktops, and mobile devices). Built as a prototype for the **Smart India Hackathon**, this platform ensures absolute data destruction compliance, generating cryptographic, tamper-evident proofs backed by blockchain technology.

🌐 **Live Demo:** [https://aiwhiping.vercel.app](https://aiwhiping.vercel.app)

---

## 🚀 The Problem & Solution
E-waste recycling often leads to catastrophic data leaks because devices are discarded without verifiable data sanitization. 

**SecureWipe solves this by providing:**
1. A streamlined inventory registry for retired hardware.
2. Industry-standard erasure protocols (NIST 800-88, DoD 5220.22-M).
3. Immutable, cryptographically signed certificates to prove zero-data recovery.

---

## ✨ Key Features
* **Interactive Secure Wipe Console:** Simulated execution of multi-pass data sanitization algorithms.
* **Tamper-Evident Certificates:** Auto-generated PDF-style compliance documents with SHA-256 hashes.
* **Blockchain Ledger Proof:** A mock Block Explorer verifying the sanitization record on a Proof-of-Stake network.
* **QR Asset Verification:** Simulated camera scanning to instantly validate physical device labels against the immutable ledger.
* **System Audit Logs:** A comprehensive chronological timeline tracking operator actions for strict compliance.
